# China Dip Radar

A Streamlit dashboard for screening A-shares and ETFs for statistically unusual drawdowns.

Features:
- Popular A-share / ETF dip ranking
- Custom watchlist scan
- Single ticker analysis
- 0.5 / 1 / 1.5 / 2 / 2.5 / 3 volatility-step levels
- Historical backtest using ex-ante 20-day realized volatility

## Deploy on Streamlit Community Cloud

Use:
- Repository: `zoey501/china-dip-radar`
- Branch: `main`
- Main file path: `app.py`

This project uses public market-data interfaces through AKShare. Data availability and latency may vary.
